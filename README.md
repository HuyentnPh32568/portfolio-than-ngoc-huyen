# Creative Portfolio — Graphic Designer & Video Editor

A modern responsive Next.js portfolio for Thân Ngọc Huyên for showcasing graphic design and video editing work.

## Quick start

Requires Node.js 24+.

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

Push the project to GitHub, then import that repository at https://vercel.com/new. Vercel detects Next.js automatically.

## Customize

- `src/app/page.tsx`: edit name, intro, project titles, categories, skills, and contact/social links.
- `src/app/globals.css`: edit styling and project art.
- Replace the **placeholder** `your-email@example.com` address with your real email.
- Project visuals are illustrative CSS concepts, **not actual work samples**. Replace them with genuine portfolio assets as desired.
- Seven submitted videos are included in `public/videos/`, along with thumbnails in `public/thumbs/`.

## Website cloner skill

This standalone portfolio was created as a Next.js site. It does not bundle the original `ai-website-cloner-template` skill. To use that skill, obtain it from https://github.com/JCodesMore/ai-website-cloner-template and follow the upstream instructions.

The email address and Behance/Instagram links are placeholders. Change them before deployment.
